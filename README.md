# MIS-Reporting-Banking-Dashboard
MIS (Management Information System) Reporting is used to collect, organize, analyze and present banking data in a meaningful format. 
📊 Excited to Share My Advanced Excel Project – Bank Customer Dashboard! 📊
I am excited to share my Bank Customer Dashboard, which I created using Microsoft Excel as part of my Advanced Excel learning journey.
In this project, I analyzed bank customer data and created an interactive dashboard to understand customer demographics, account balances, job classifications, regions, gender distribution, and customer joining trends.
🔹 Key KPIs Included:
📌 Total Customers
📌 Total Bank Balance
📌 Average Balance
📌 Highest & Minimum Balance
📌 Male & Female Customers
📌 Total Regions
🔹 Analysis & Visualizations:
📊 Region-wise Balance Analysis
📊 Gender-wise Customer Analysis
📊 Job Classification Analysis
📊 Age Group Analysis
📊 Customer Joining Trend
📊 Interactive Slicers for Region, Gender, Job Classification, Age Group, and Month Joined
🛠️ Skills Used:
✔ Microsoft Excel
✔ Pivot Tables & Pivot Charts
✔ Slicers
✔ Data Analysis
✔ Dashboard Design
✔ Excel Functions & Formulas
This project helped me strengthen my Advanced Excel, data analysis, and dashboard development skills. I am continuing to work on more projects to build my portfolio and grow as a Data Analyst.
